# Glossario italiano

Le traduzioni italiane usano le parole del *Manuale dell'utente* italiano del JD-Xi (Roland),
così chi passa dal manuale al programma trova gli stessi nomi.

**Restano in inglese**, come sul pannello e nel manuale:

- **Nomi stampati sul pannello:** Part Select, Program, Tone [-] [+], OCTAVE Down/Up, ARPEGGIO On/Key Hold, Favorite, Effects, Vocoder, Cutoff, Resonance, Tap, Menu/Write, Step Rec, Real Time Rec.
- **Nomi delle parti:** Digital Synth 1/2, Drums, Analog Synth. Nelle schede: Digital 1/2, Analog, Drums.
- **Nomi dei parametri come sul display:** Sync Mode, Mic Sel, Pitch Bend Range, Attack Time, ecc. Anche Partial, Velocity, AutoPitch, Vocal FX, reverb, delay, drum kit, LFO.

**In italiano**, come nel manuale:

| Inglese | Italiano |
|---|---|
| program / user program / preset program | programma / programma utente / programma preimpostato |
| tone | tono (non "timbro") |
| part | parte (la parte Drums, la parte Analog Synth) |
| favorite | preferito |
| pattern sequencer | sequencer di pattern |
| step / measure | passo / misura |
| step recording / real-time recording | registrazione a passi / registrazione in tempo reale |
| arpeggiator | arpeggio |
| octave | ottava |
| filter / oscillator / envelope / level | filtro / oscillatore / inviluppo / livello |
| bank | banco |
| effects (in un testo) | effetti |
| MIDI file | file MIDI |
| log | log |
| Off-line / connected / unstable connection | Off-line / collegato / comunicazione instabile |
| Save on the JD-Xi (WRITE) | Salva sul JD-Xi (il JD-Xi conserva solo con WRITE) |
| context line / origin / temporary | riga di contesto / origine / temporaneo |
| New sound / From scratch (Init) | Nuovo suono / Da zero (Init) |
| slot (program slot) | posto (E01–H64) |

Per controllare un testo nuovo: `python -m building.i18n check`.
