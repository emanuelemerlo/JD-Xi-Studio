Editor Windows
==============

The Editor Windows are the sophisticated command centers of JD-Xi Studio—comprehensive, specialized interfaces that provide deep, granular control over every aspect of your Roland JD-Xi synthesizer.

Available Editors
=================

* :doc:`JDXi Instrument Window <instrument>` - The main instrument interface and control center
* :doc:`Editor Windows Overview <editor>` - Comprehensive guide to all specialized editors
* :doc:`Digital Synth Editors (Parts 1 & 2) <digital_synth>` - Multi-partial digital synthesis control
* :doc:`Analog Synth Editor <analog_synth>` - Classic analog synthesis with warm, organic sound
* :doc:`Drum Kit Editor <drum_kit>` - Professional drum sound design with 36 individual voices

The menus
=========

The keyboard window's menus open the editors and do what the editors do, from anywhere; each
item's tooltip says what it loads or sends, and where.

* **File** — **Programs…** (the Programs tab); **Open a sound file (patch)…** loads a program and
  its tones from a ``.jsz`` / ``.msz`` file and sends them to the JD-Xi; **Save the sounds to a
  file (patch)…** saves them to a file (not on the JD-Xi); the MIDI Player's file: open, save,
  save as, recent files.
* **JD-Xi** — what talks to the instrument: **Save on the JD-Xi…** (the guided WRITE into a user
  slot), **Send all to the JD-Xi…** (every value of the open editors into its current program;
  asks first, writes nothing in its memory), **Read the user programs (E–H)…** (loads the 256 user
  slots one by one and keeps their names in the library), **MIDI Configuration…**,
  **Self-test with the JD-Xi…**.
* **Parts** — Digital 1, Digital 2, Analog, Drums (Ctrl+1–4), Program: common and parts, Recipes.
* **Effects** — Effects (Ctrl+6), Vocal FX (Ctrl+7).
* **Playback** — Arpeggio (Ctrl+5), Pattern (Ctrl+8), MIDI Player (Ctrl+9).
* **Tools** — Settings, Preferences (Ctrl+,), MIDI Monitor, SysEx Debugger, Log Viewer.
* **Window** — show the editors or the keyboard, keyboard on top, line them up.
* **Help** — Documentation (F1), Check for Updates, About.
